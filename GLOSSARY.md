# NEON DUNGEON

A mobile-first neon action-adventure in which an AI prototype escapes the system that woke it. This glossary fixes the story and structure vocabulary used by the redesign planning.

## Language

**Iteration**:
A prior in-fiction instance of the protagonist. The player's protagonist is the catalyst-ready iteration, awake with data left by earlier ones.
_Avoid_: Loop, life, previous run

**Run**:
One player attempt, from waking to death or exit. Runs are what the player replays.
_Avoid_: Loop, playthrough, iteration

**Act**:
A story chapter spanning one or more areas. Short unskippable cutscenes occur only between acts.
_Avoid_: Chapter, level, world

**Area**:
A distinct place with its own hazards, enemy families, objectives and pacing.
_Avoid_: Biome, floor band, level theme

**Clue**:
A discoverable fact that unlocks story progress. Clues persist across runs.
_Avoid_: Key, memory, lore entry

**Fork**:
An optional moral choice with a cost that changes the cast and the available endings, then returns to the main story line.
_Avoid_: Branch, side quest

**Emotion sidechain**:
The protagonist's emotional processing, triggered only by deep story events (betrayal, moral weight), never by combat kills.
_Avoid_: Mood, morale
